# Sandbox-C
Консольная утилита для запуска потенциально опасных приложений. Инструмент реализует многоуровневую изоляцию на основе штатных механизмов ядра: chroot, namespaces, seccomp-bpf и принудительный сброс привилегий

=== Возможности ===
Изоляция файловой системы
Создание отдельного пространства имён монтирования (CLONE_NEWNS) и chroot в подготовленный jail-каталог. Системные директории (/usr, /lib, /bin, /etc и др.) монтируются в режиме «только чтение» для минимально необходимого рабочего окружения.

=== Как работает === 
Политика «запрещено всё, что не разрешено явно» (т.е работа по белым спискам). Белый список включает только безопасные вызовы для работы с памятью, вводом-выводом, файловой системой и базовым жизненным циклом процесса. Любое нарушение немедленно завершает процесс сигналом SIGSYS.

В системе создается папка-изолятор jail, в которую помещается потенциально вредоносная программа. После настройки изоляции root-права сбрасываются до указанного непривилегированного пользователя. Дополнительно устанавливается флаг PR_SET_NO_NEW_PRIVS, предотвращающий любое повышение привилегий через SUID-бинарники. В итоге вирусняк не видит ничего за пределами этой папки и не может навредить системе или украсть конфиденциальную информацию.

Родительский процесс отслеживает завершение изолированного потомка: анализирует код возврата, факт убийства сигналом и специально выделяет срабатывание seccomp-фильтра (сигнал 31).

Фильтрация системных вызовов реализована через библиотеку libseccomp и загружается в ядро до передачи управления целевой программе.

=== Технологии ===
Язык: C11 с расширениями GNU
Компилятор: GCC
Стандартная библиотека: glibc
Изоляция: libseccomp, пространства имён Linux, chroot
Системные вызовы: fork, execvp, wait, mount, unshare, prctl, setuid/setgid

=== Требования ===
Операционная система: Linux (ядро ≥ 3.17 для поддержки seccomp(2))
Архитектура: x86-64
Права суперпользователя (root) для запуска
Установленная библиотека libseccomp-dev
Подготовленный jail-каталог: /home/user/jail с базовой структурой ФС

КОМПИЛЯЦИЯ:
как обычно в gcc, но в флагом -lseccomp
ИСПОЛЬЗОВАНИЕ:
sudo ./sandbox [опции песочницы] -- <целевая программа> [аргументы программы]

В РЕПОЗИТОРИИ:
Тестовое вредоносное ПО: virus1, 2 и 3.
virus1 - пытается читать дескрипторы, доставшиеся в наследство от родителя
virus2 - пытается открыть симлинки, указывающие наружу (или в пределах изолятора)
virus3 - пытается использовать запрещенный системный вызов
